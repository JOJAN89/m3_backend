# Events API

## Project Overview

This project is a REST API built using Express and TypeScript. It allows users to create, read, update, and delete events. The API is designed to demonstrate backend development concepts such as routing, validation, security, and API documentation.

This project also focuses on secure configuration and proper documentation. It uses dotenv for environment variables, Helmet for security headers, CORS for controlling access, Joi for validation, and Swagger for API documentation.

---

## Features

- Create, update, delete events
- Input validation using Joi
- Secure API using Helmet and CORS
- Environment variables using dotenv
- API documentation using Swagger (OpenAPI)
- Clean project structure with routes, controllers, and middleware
